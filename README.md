# Entrevista C-Level ESG | Balmoral

Aplicação web estática para automatizar o roteiro de entrevistas com C-levels para o Troféu ESG.

## O que contém

- Roteiro com 6 blocos temáticos.
- 24 perguntas para coleta de narrativa, evidências e próximos passos.
- Checklist operacional para condução da reunião.
- Gerador de pauta personalizada por executivo, empresa/unidade e foco da conversa.
- Botão para copiar o roteiro completo e compartilhar com Amanda, GG ou o time responsável.

## Como rodar

```bash
npm run dev
```

Acesse `http://localhost:3000`.

## Scripts

- `npm run dev`: inicia um servidor local com Python na porta 3000.
- `npm run check`: valida a sintaxe do JavaScript principal.
